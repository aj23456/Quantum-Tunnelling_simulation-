# Quantum-Tunnelling_simulation-
# It builds a discrete Hamiltonian matrix using a finite-difference method to simulate a wave packet colliding with a barrier. It then compares this dynamic simulation against a theoretical WKB (Wentzel-Kramers-Brillouin) approximation to check for errors.
#It uses VPython for a real-time web-canvas visualization and Matplotlib to plot the final error margin between the simulation and theory.
